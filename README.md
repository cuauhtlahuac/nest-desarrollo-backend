# 🚀 Modern Backend Development with NestJS

This repository contains the projects and code written while completing the [NestJS Back-end Development](https://www.udemy.com/course/nest-framework) course. 

## 📝 Course Summary
This course is a comprehensive deep dive into **NestJS**, a progressive Node.js framework for building efficient, reliable, and scalable enterprise-grade backend applications. The curriculum transitions from fundamental architectural patterns to advanced real-world implementations, focusing heavily on robust API design and database integrations.

## 🛠️ Tech Stack & Tools
- **Framework:** NestJS (Node.js)
- **Language:** TypeScript
- **Database:** PostgreSQL
- **ORM:** TypeORM
- **Containerization:** Docker & Docker Compose
- **Security:** JWT (JSON Web Tokens), Passport.js
- **Testing:** Jest (Unit & E2E Testing)

## 💡 Key Concepts Mastered
- **Architectural Patterns:** Structuring applications using Dependency Injection, Modules, Controllers, and Providers (Services) under the hood.
- **Database Management:** Integrating PostgreSQL with TypeORM, mapping entities, handling relational data, and performing complex CRUD operations safely.
- **Authentication & Authorization:** Implementing secure user registration, password hashing (bcrypt), login workflows, and role-based route protection using Guards and JWT.
- **Data Validation & Transformation:** Using NestJS Pipes and Data Transfer Objects (DTOs) to validate incoming requests and maintain strong typing at the application boundaries.
- **Local Dev Environment:** Utilizing Docker to spin up isolated, reproducible database containers for seamless local development.
- **Error Handling:** Setting up Exception Filters for centralized, consistent error formatting across the API.
- **Testing:** Writing isolated Unit tests and End-to-End (E2E) tests to ensure business logic reliability.
